CONFIGURATION DU DIRECT

Gérer le flux live.

Colle l'URL de ton direct YouTube pour préparer le lecteur du site.

À noter : cette interface est un outil de configuration, pas encore un espace sécurisé. Le lien du direct n'est pas privé, mais le panneau n'a ni compte utilisateur ni protection d'accès. N'y saisis jamais de mot de passe.

Ouvrir YouTube Studio ↗Voir les directs ↗

Appliquer la modification

  1. Colle l'URL du direct et clique sur le bouton ci-dessus.
  2. Le navigateur télécharge site-settings.json.
  3. Remplace ce fichier à la racine du dépôt GitHub par le fichier téléchargé.
  4. Vercel redéploiera le site avec le nouveau lien.

Pour changer le direct sans redéploiement, il faudra connecter une base de données sécurisée avec authentification (Supabase ou Firebase).
