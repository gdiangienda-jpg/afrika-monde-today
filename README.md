# AFRIKA MONDE TODAY — Site web

Site vitrine responsive pour la chaîne AFRIKA MONDE TODAY, en HTML, CSS et JavaScript natifs.

## Fichiers
- `index.html` : structure du site
- `style.css` : identité visuelle, animations et adaptation mobile
- `script.js` : menu mobile, animations d'apparition et barre de progression
- `assets/logo-afrika-monde-today.webp` : logo de la chaîne
- `assets/banniere-afrika-monde-today.webp` : bannière d'arrière-plan

## Déploiement sur Vercel
1. Connecte le dépôt GitHub à Vercel.
2. Framework Preset : **Other**.
3. Laisse la commande de build vide et utilise le dossier racine comme sortie.
4. Clique sur **Deploy**.

## À personnaliser
- Remplace les liens sociaux `href="#" ` par les liens officiels.
- Intègre le flux vidéo réel (YouTube Live, HLS ou autre) dans la section `#direct`.
- Remplace les actualités et programmes de démonstration par le contenu officiel.

Le site est statique et ne nécessite ni backend ni variables d'environnement.
